# fuDO - Food Ordering Web Application

## Overview
**fuDO** is a front-end web application designed to provide a seamless and interactive food ordering experience. The project features a clean, responsive user interface where users can navigate through different sections to browse food items, discover available discounts, and confirm their orders. 

## Features
* **Landing Page (`index.html` / `home.html`):** An engaging homepage featuring dynamic background media and intuitive navigation.
* **Menu Selection (`items.html`):** A dedicated interface to browse through a variety of food items.
* **Special Offers (`discount.html`):** A promotional page displaying active discounts and deals.
* **Order Confirmation (`Confirmation.html`):** A checkout/confirmation interface to finalize user orders.

## Tech Stack
* **HTML5:** Semantic structure and page layouts.
* **CSS3:** Custom styling, layouts, and responsive design.
* **Vanilla JavaScript:** Dynamic page interactions and front-end functionality.

## Getting Started

To run this project locally, no specialized backend server or build tools are required.

1. **Clone the repository:**
   ```bash
   git clone <your-repository-url>
   ```
2. **Navigate to the project directory:**
   ```bash
   cd fuDO-main/fuDO(2)
   ```
3. **Run the application:**
   Simply double-click `index.html` to open it in your default web browser. For a better development experience, it is recommended to use an extension like [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) in VS Code.
